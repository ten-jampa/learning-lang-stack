Stack Map cheat sheet

One rule: harness = owns the model loop; runtime = owns execution. Everything else follows.

LayerWhat it isReach for it when…
LangChain
framework		Models, tools, create_agent (proven ReAct loop), middlewareYou want a tool-calling agent in minutes; loop shape is standard
LangGraph
runtime		StateGraph: state + nodes + edges; durable execution, streaming, checkpoints, interruptsLoop shape is custom (branches, multi-actor, approvals, long runs)
Deep Agents
harness		Opinionated agent on create_agent: planning, subagents, filesystem, context mgmt, skills, HITLLong-horizon work (research/coding) where you want batteries included
LangSmith
platform		Tracing, evals, deploy, StudioAgent works locally; now debug/eval/ship it

Decision in 10 seconds

  1. Standard tool loop? → create_agent (LangChain).
  2. Need planning + subagents + files out of the box? → create_deep_agent.
  3. Need a different loop shape / hard boundaries? → StateGraph (LangGraph).
  4. Any CompiledStateGraph can be a Deep Agent subagent — layers compose.

Minimal shapes (from memory)

# LangGraph: state → node → edge → compile → invoke
from langgraph.graph import StateGraph, MessagesState, START, END
g = StateGraph(MessagesState)
g.add_node("llm", fn)          # fn(state) -> {"messages": [...]}
g.add_edge(START, "llm")
g.add_edge("llm", END)
app = g.compile()
app.invoke({"messages": [{"role": "user", "content": "hi"}]})

# LangChain: harness owns the loop
from langchain.agents import create_agent
agent = create_agent(model="claude-sonnet-4-5-20250929",
    tools=[get_weather], system_prompt="You are a helpful assistant")

# Deep Agents: harness + batteries
from deepagents import create_deep_agent
agent = create_deep_agent(tools=[...])  # planning, subagents, fs included
